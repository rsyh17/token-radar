How the value is derived

#ProtocolCategoryChainsTVL7dYears tokenlessMultipleImplied value

Implied value is this radar's own model claim, derived only from the sealed snapshot's figures — TVL, seven-day growth, time run with no token, and what traded peers' tokens fetch per TVL dollar. It is not a prediction that a token will be issued. Protocols whose token already trades, and wrapped, staked or bridged products of them, are set aside: they are not waiting on a launch.
