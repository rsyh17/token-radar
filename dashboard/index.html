How the value is derived

Implied value = TVL × the category’s median market-cap/TVL ratio among traded peers, blended toward the all-category median by peer count, then adjusted by momentum (7-day TVL change), longevity (+4% per year run with no token, up to six) and breadth (+1.5% per extra chain). Nothing is ranked by name or by hand.

Category multiples — from the snapshot itself

CategoryTraded peersMedianApplied

A category with few traded peers has a noisy median, so the applied multiple is the peer-count blend (n × category median + 4 × all-category median) / (n + 4). Categories with fewer than three traded peers fall back to the all-category median outright.
